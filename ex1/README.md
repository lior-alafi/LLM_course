# Exercise 1 — Transformer LM from scratch

Tiny transformer language model (attention, MLP, tokenization) trained on English and Hebrew text, built without relying on a framework's model classes.

See [`code-and-data/code/`](code-and-data/code) for the implementation (`transformer.py`, `attention.py`, `mlp.py`, `lm.py`, `training.ipynb`) and [`code-and-data/figs/`](code-and-data/figs) for training/loss curves across hyperparameter sweeps.

Run: `cd code-and-data/code && uv run main.py`
